# AtteConDA GitHub Pages English replacement package

This package contains an English GitHub Pages replacement set:

- `docs/index.html`: English project page code.
- `docs/assets/*.png`: translated replacement figures for the project page.
- `.github/workflows/pages.yml`: GitHub Actions workflow for Pages deployment.

Copy `docs/` and `.github/workflows/pages.yml` into the root of `ShogoNoguchi/AtteConDA`, commit, and push.

For Windows users, follow the separate `Howto.docx` document.
